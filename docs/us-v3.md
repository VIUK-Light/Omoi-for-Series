# Omoi for Us v3

Family／Friendsを、身近な人の選択を予想するゲーム「Omoi for Us」に統合します。

## 確定した仕様

- 2〜6人、スマホ1台。家族166問・友人150問の選んだ種類から引き、深さの選択は設けません。
- 主役だけが画面で3択から答えを選びます。選択後は印を出さず、他の人が一斉に予想してから「答えを公開」で回答を表示します。
- 予想と採点は1問につき1回。主役以外の的中者に各1点、全員が1回ずつ主役になると終了です。
- 条件変更は、公開後に任意で開くおまけの会話です。2回目の予想・回答入力・採点は行いません。
- 予想前は選び直しができ、公開後は答えを確定します。「次の人へ」までは的中者の修正、または同じ主役でのパスができます。
- 同じタブ内の保存に対応します。選んだ回答はその問いの間だけ保持し、完了後は主役・問い・的中者のIDだけを残します。
- Usはレビュー待ちの開発プレビューです。標準の公開判定ではローカルでのみ確認できます。本人限定Sitesの確認用コピーには、対応するオリジンでの例外を設けています。

## 316問の改稿と原文

元の`shared/questions/family.json`（166問）と`friends.json`（150問）、深掘り、表示文は変更していません。保存時点は`f0042facf16bc8f792a19fa912b3b5fe17618346`、保存用タグは`archive/family-friends-before-us-v3`です。タグは共通コードを含む移行前リポジトリ全体を指します。

個別の編集内容は`tools/us-edits/family.psv`と`friends.psv`にあります。一行の形式は「元の配列での1始まりの番号 | 問い | 選択肢1 | 選択肢2 | 選択肢3 | 追加条件」です。汎用テンプレートから選択肢や条件を自動補完しません。思い出に関する元の問いは、その思い出をどう話す・残す・振り返るかを選ぶ場面として改稿しています。

番号対応は`source-contract.json`のコミットと元ファイル全体のSHA-256に固定しています。並びや元データが変わると生成を停止します。生成JSONの各問には元の質問ID・本文ハッシュ・カテゴリ・Levelも記録し、1対1の対応を検証します。生成元はCodexによる改稿として記録し、旧データの生成元や承認を転用しません。改行は改稿表に明記した`\n`だけを採用し、表示時の自動文節分割は行いません。

```sh
node tools/build-us-dataset.mjs
node tools/build-us-dataset.mjs --check
node tools/verify-us-dataset.mjs
```

現行の編集記録は全問がレビュー待ちです。再生成しても公開・承認は行いません。公開準備を行う際は、編集記録・承認記録・データ・マニフェストの整合を確認する変更を別途用意してください。

## 実装とカードUI

`us/game-engine.mjs`は`choose → guess → score → 次の主役／results`を扱います。保存形式はバージョン3です。回答を選んだ後も`guess`画面には選択状態を描画せず、`REVEAL`だけが公開に進めます。公開後の選び直しはできません。

`us/card-view.mjs`は、公開前の両面に選択した答えの参照や印を出しません。主役だけが選ぶ画面にのみ選択ボタンを置き、予想画面の3択は参照用です。回答の番号は現在の問いの保存状態にだけ保持し、サーバーへ送信しません。

的中者は集合として扱い、主役は選択対象から除きます。`TOGGLE_CONDITION`は会話用の裏面を開閉するだけで、回答・的中者・得点を変更しません。「次の人へ」の1回でその問いを確定し、重複操作では加点しません。パスと途中終了は未完了の問いの得点を除きます。

旧形式や更新前のデータに対応しない保存状態は更新案内とともに新規開始へ戻します。別の種類の旧URLを開いた時は、開始操作まで前のゲームを上書きせず、戻る選択肢も表示します。

参加者を追加する時は未使用の既定名を選びます。空欄で自動的に付く名前も考慮し、途中の参加者を削除して追加しても既定名が重複しません。

既存Omoi forの`shared/question-card.mjs`と`shared/styles.css`を使用します。カード幅は通常最大340px、短い問いの縦横比は63:88、長文は自然に高さが伸びます。公開後に任意で裏返して条件を表示し、非表示面は`aria-hidden`と`inert`で操作・読み上げから外します。動きを減らす設定に対応します。

「大きく表示」ではカード幅を最大480px、選択肢を20pxにします。UD書体は同梱し、外部フォント配信を使いません。フォントの由来と再生成方法は`us/fonts/README.md`を参照してください。

`docs/design/omoi-for-us-v3-concept.png`と`docs/screenshots/`は初期案の記録です。現在の見た目の基準は既存Omoi forのカードUIです。

## 確認する流れ

開始 → 主役だけで画面選択 → 選択状態がない予想画面 → 公開 → 的中者 → 次の人へ → 結果。おまけの会話を開かずに1周でき、開いた場合も得点は増えません。保存から再開した予想画面でも選択状態を表示しません。

6人全員的中の1周は、設定・パス・おまけの操作を除いて24タップ、全員外れは18タップです。全員1回ずつ主役となり、得点上限は1人につき5点です。

Usの全316問は通常・拡大表示の320・390・768・1280pxで確認します。共通部品を変えた時はCouples・Adults・Self-Careの既存カードも確認します。今回のルール変更で質問データや旧版の原文は変更していません。
