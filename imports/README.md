# Adults追加データの保全と取り込み

## 初回復旧時の保留

Adultsの実行用JSONには64件の質問オブジェクトの後に、追加30件を含む入れ子の配列がありました。このため画面の形式チェックで読み込みを停止していました。

- `adults-before-format-fix.json`: 修正前ファイルの全バイトを保存したバックアップ。
- `adults-pending.json`: 追加30件をフラット化した保留データ。本文と作成元の値は受け取ったまま保持しており、作成元や内容を承認した記録ではありません。
- 実行用`shared/questions/adults.json`: 元の形式検証を通る64組に復旧。AI初期案・pending・unpublishedの状態を維持しています。

追加分は構造だけでなく、作成元の表記とシリーズの内容方針の検証も必要です。アプリのマニフェストはこのフォルダーを読み込みません。取り込みや公開を承認する処理は行っていません。

保留中の入力JSONと完全バックアップは`imports/.gitignore`でGitの対象外にし、ローカルに保持します。

## 2026-10-16の取り込み

ユーザーの許可後、追加30組を原文のまま取り込み、実行用Adultsを94組へ更新しました。このフォルダーの原本とバックアップは保持しています。追加分の出典は`user-provided`として扱い、受け取った作成元の申告を`source.original`にそのまま保存しました。AIの生成元を確認した、またはGrokの審査を検証したという記録は付けません。原文の整合性はSHA-256で検証します。
